# Flip Reader Upload

Browser page that sends a book (.txt) or a sleep screen picture to a DIY e-paper reader
(a reflashed Hanshow shelf label) over Web Bluetooth.

Open it at https://pimveha.github.io/flip-reader-upload/ in Chrome or Edge on a computer or an
Android phone (on iPhone: the Bluefy browser). The text is cleaned up and compressed in the
browser; nothing is uploaded anywhere except to the reader.

These files are published from the main (private) project, where they are tested against the
Python tools.
